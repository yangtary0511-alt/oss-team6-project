## 📌 프로젝트 소개

컴퓨터는 다양한 하드웨어 부품이 서로 연결되어 작동하는 전자 장치입니다.
각 부품은 고유한 역할을 수행하며, CPU의 연산, RAM의 임시 저장,
SSD와 HDD의 데이터 보관, GPU의 그래픽 처리, 메인보드의 연결 기능이
유기적으로 결합되어 컴퓨터 시스템이 완성됩니다.

이 프로젝트에서는 컴퓨터를 구성하는 주요 하드웨어의 개념과 작동 원리,
특징 및 상호 관계를 정리합니다. 각 부품의 역할을 이해하면 컴퓨터의
성능이 결정되는 원리뿐 아니라, 사용 목적에 적합한 시스템을 구성하는
방법도 배울 수 있습니다.

## 🧩 컴퓨터를 구성하는 핵심 부품

컴퓨터의 성능은 하나의 부품만으로 결정되지 않습니다.
CPU와 GPU의 연산 능력, RAM의 용량, 저장장치의 속도,
메인보드의 호환성과 확장성 등이 함께 작용합니다.

| **RAM** | 실행 중인 프로그램과 데이터 임시 저장 | 빠르게 접근할 수 있는 휘발성 메모리 | - [RAM](RAM_요약.md) |

## ⚙️ 주요 하드웨어 살펴보기

### 🧠 1. CPU (Central Processing Unit)

CPU는 컴퓨터의 중앙처리장치로, 프로그램의 명령어를 해석하고 실행하며
산술 연산과 논리 연산을 수행합니다. 운영체제 실행, 프로그램 처리,
파일 작업 등 컴퓨터의 전반적인 동작에 관여합니다.

CPU의 성능은 클럭 속도뿐 아니라 코어와 스레드 수, 아키텍처,
캐시 메모리, 전력 및 발열 특성 등에 영향을 받습니다.
코어는 명령을 처리하는 핵심 연산 단위이며, 캐시는 CPU가 자주 사용하는
데이터를 빠르게 제공하여 메모리 접근 지연을 줄이는 역할을 합니다.

**핵심 키워드:** 명령어 처리 · 연산 · 코어 · 스레드 · 캐시

### 🧮 2. RAM (Random Access Memory)

RAM은 현재 실행 중인 프로그램과 작업에 필요한 데이터를 임시로 저장하는
주기억장치입니다. CPU가 필요한 데이터에 빠르게 접근할 수 있도록 작업 공간을
제공하며, 여러 프로그램을 동시에 실행할 때 중요한 역할을 합니다.

RAM은 전원이 꺼지면 저장된 데이터가 사라지는 휘발성 메모리입니다.
일반 PC의 주기억장치에는 주로 DRAM이 사용되며, SRAM은 CPU 캐시 등에
활용됩니다. RAM의 용량이 부족하면 저장장치를 활용하는 가상 메모리의
사용이 늘어나 시스템 반응 속도가 저하될 수 있습니다.

**핵심 키워드:** 임시 저장 · 휘발성 · DRAM · SRAM · DDR4 · DDR5

### 💾 3. SSD · HDD (Storage Devices)

SSD와 HDD는 운영체제, 프로그램, 문서, 사진, 영상 등의 데이터를 보관하는
저장장치입니다. RAM과 달리 전원이 꺼져도 데이터가 유지됩니다.

SSD는 NAND 플래시 메모리에 데이터를 저장합니다. 움직이는 부품이 없어
데이터 접근이 빠르고 소음이 적으며, 운영체제 부팅과 프로그램 실행 시간을
줄이는 데 유리합니다. HDD는 회전하는 자기 디스크와 읽기·쓰기 헤드를
사용하여 데이터를 기록합니다. 일반적으로 용량당 가격이 낮아 대용량 파일을
보관하는 데 적합하지만, 기계적 부품이 있어 충격과 소음에 주의해야 합니다.

**핵심 키워드:** 영구 저장 · NAND 플래시 · 자기 디스크 · 속도 · 용량

### 🎮 4. GPU (Graphics Processing Unit)

GPU는 이미지와 영상 처리에 필요한 연산을 수행하는 장치입니다.
많은 데이터에 유사한 연산을 동시에 수행하는 병렬 처리에 강점이 있어
게임 그래픽, 3D 렌더링, 영상 편집, 인공지능 연산 등에 활용됩니다.

게임에서는 물체의 위치와 색상, 조명 등의 정보를 계산하여 화면을 구성합니다.
GPU가 처리하는 그래픽 데이터와 연산 중간 결과를 저장하는 데에는 VRAM이
사용됩니다. GPU는 그래픽카드의 핵심 칩이며, CPU와 역할을 나누어 처리함으로써
복잡한 작업을 효율적으로 수행할 수 있습니다.

**핵심 키워드:** 병렬 처리 · 그래픽 렌더링 · VRAM · 3D · 영상 처리

### 🔌 5. 메인보드 (Motherboard)

메인보드는 CPU, RAM, 저장장치, 그래픽카드 등 주요 부품을 연결하는
핵심 회로 기판입니다. 각 부품 사이의 데이터 통신을 지원하고 전원 공급을
연결하며, 시스템 전체의 호환성과 확장성에 영향을 미칩니다.

CPU 소켓, 메모리 슬롯, 전원부, PCIe 슬롯, M.2 슬롯, SATA 커넥터,
USB 및 네트워크 연결부 등이 주요 구성 요소입니다. 칩셋은 CPU와 주변 장치의
연결 및 기능 지원에 관여합니다. 메인보드는 ATX, Micro-ATX, Mini-ITX 등으로
구분되며, 크기와 슬롯 수에 따라 확장 가능성이 달라집니다.

메인보드를 선택할 때에는 CPU 소켓과 지원 세대, 메모리 규격,
케이스 크기, 저장장치 연결 방식, 확장 슬롯 및 필요한 단자를 확인해야 합니다.

## 🔄 부품들은 어떻게 함께 작동할까?

컴퓨터에서 프로그램을 실행하면 저장장치에 보관된 프로그램과 데이터가
RAM으로 읽혀 들어옵니다. CPU는 RAM에서 필요한 명령어와 데이터를 가져와
작업을 처리합니다. 그래픽 처리가 필요한 경우 CPU는 GPU에 관련 작업을
전달할 수 있으며, GPU는 그래픽 연산을 수행하고 필요한 결과를 VRAM에
저장하거나 화면 출력에 활용합니다.

이 모든 부품은 메인보드를 통해 연결되며, 전원 공급 장치(PSU)는 각 부품이
작동하는 데 필요한 전력을 제공합니다. 각 부품의 성능과 연결 방식이
조화를 이루어야 전체 시스템의 성능을 효과적으로 활용할 수 있습니다.

예를 들어 RAM 용량이 부족하면 여러 프로그램을 동시에 실행할 때 불편할 수
있고, 저장장치가 느리면 프로그램 실행과 파일 로딩에 시간이 더 걸릴 수 있습니다.
게임이나 3D 작업에서는 GPU 성능이 중요하며, 복잡한 계산이나 프로그램 실행에서는
CPU 성능도 중요한 영향을 미칩니다.
